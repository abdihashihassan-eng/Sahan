# SAHAN DATA

Platform for buying data packages (internet, call minutes), referrals, competitions, and rewards.

## ✨ Features
- Registration with referral link (`?ref=CODE`)
- Promo code system (4 digits) for login & competitions
- 5-step order wizard with USSD auto-dial
- Leaderboard (top referrers, sellers, promoted)
- Weekly, monthly, annual rewards
- Admin panel (orders & products management)
- Real-time live feed
- Mobile-friendly responsive design

## 🛠️ Backend
- Supabase (PostgreSQL)
- RPC functions
- Triggers for `total_referrals`
